# About ECJsonStorage
 ECJsonStorage is a JS wrapper to the [ExtendsClass JSON Storage API](https://extendsclass.com/json-storage.html) offering of Cyril Bois.

 For API usage, you need an API-Key which you can apply [here](https://extendsclass.com/create-account-form).

 ECJsonStorage enables you to create, update, patch and delete Bins. There is a usage limit of
 - 10.000 calls per month
 - Bin size limit of 100kb
 - total account limit of 10mb.

 Documentation details will follow; for now you may wanna consult the [TS types file](dist/index.d.cts).
